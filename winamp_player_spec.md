## 🎯 Общий Замысел и Цель
Разработать легкий, быстрый и интерактивный веб-плеер в эстетике классического **Winamp**, выдержанный в мягкой **пастельной цветовой гамме** с мерцающими визуальными эффектами, анимациями и пасхалками. 

Проект должен быть оптимизирован **Mobile-First (ориентир: iPhone 14 / 15, iOS Safari)**, содержать движок всплывающих медиа-событий по таймкодам, режим скринсейвера **Windows XP ("3D Трубы")** и деплоиться в один клик на **Vercel**.

## 🎵 Функциональные Требования

### 1. Модуль Аудиоплеера (Winamp Core)
- **Источник аудио:** Прямые ссылки на `.mp3` файлы, размещенные в репозитории GitHub (с поддержкой возможности расширения до SoundCloud / YouTube API).
- **Органы управления:**
  - **Play / Pause / Stop**
  - **Seek bar / Scrubber:** Ползунок перемотки с отображением текущего времени (`00:00`) и полной длительности.
  - **Next / Previous Track:** Переключение между треками.
  - **Shuffle (Шаффл):** Режим случайного выбора следующего трека.
  - **Volume Slider:** Регулятор громкости.
  - **Main Display:** Бегущая строка (Marquee) с названием трека и битрейтом.
  - **Playlist Window:** Окно со списком всех загруженных треков с возможностью клика для воспроизведения.

### 2. Движок Пасхалок и Медиа-Триггеров (Trigger Sync System)
- Каждая песня описывается в JSON-файле `data/tracks.json`.
- В JSON задается массив медиа-триггеров, привязанных к точным секундам воспроизведения:
```json
{
  "tracks": [
    {
      "id": "track-01",
      "title": "Pastel Dreams (Demo)",
      "artist": "Lo-Fi Artist",
      "url": "https://raw.githubusercontent.com/user/repo/main/assets/audio/song1.mp3",
      "triggers": [
        {
          "time": 12,
          "type": "image",
          "src": "/assets/images/photo1.jpg",
          "effect": "fade-in",
          "position": "center",
          "duration": 6
        },
        {
          "time": 42,
          "type": "video",
          "src": "/assets/videos/clip1.mp4",
          "duration": 10
        },
        {
          "time": 88,
          "type": "popup",
          "content": "✨ Секретная пасхалка найдена!",
          "duration": 4
        }
      ]
    }
  ]
}
```
- Движок должен ежесекундно сверять `audio.currentTime` с массивом триггеров текущего трека и плавно отображать/скрывать медиафайлы поверх плеера.

### 3. Скринсейвер Windows XP ("3D Трубы")
- **Активация:** Отдельная ретро-кнопка в интерфейсе плеера («Screensaver» / «3D Pipes»).
- **Реализация:** Использование легкого Canvas 2D/3D алгоритма генерации цветных 3D-труб в стиле Windows XP.
- **Поведение:**
  - Скринсейвер переходит в полноэкранный режим (`fixed fullscreen overlay`, `z-index: 9999`).
  - Воспроизведение музыки **НЕ прерывается**.
  - При любом касании экрана (tap/click) скринсейвер мгновенно плавно исчезает, возвращая пользователя к интерфейсу плеера.

## 📁 Структура Проекта для Vercel

```text
/
├── index.html          # Главный HTML-каркас с разметкой плеера
├── css/
│   ├── style.css       # Пастельная стилизация, гриды, шрифты и мерцания
│   └── winamp.css      # Стилизация компонентов плеера и оверлеев
├── js/
│   ├── app.js          # Главная точка входа и инициализация jQuery Munch
│   ├── player.js       # Аудио-движок, шаффл, регулятор громкости
│   ├── triggers.js     # Движок таймкодов и медиа-событий из tracks.json
│   └── screensaver.js  # Canvas-движок скринсейвера "3D Трубы"
├── data/
│   └── tracks.json     # Конфигурация треков, MP3-ссылок и пасхалок
├── assets/
│   ├── audio/          # Запасные локальные MP3
│   ├── images/         # Картинки, гифки, пасхалки
│   └── videos/         # Короткие видео-фрагменты
└── vercel.json         # Конфигурация деплоя Vercel
```
